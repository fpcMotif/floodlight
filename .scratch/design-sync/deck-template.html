The content inside the glass, drawn to Spotlight's own standard.

#1 gives the panel a Liquid Glass shell. This is what goes inside it: a real type scale and tint palette instead of scattered inline literals, a Top Hit that earns the Return key without reading the list, symbol rows on tinted continuous-curve tiles instead of flat rectangles, and a panel that grows on a spring instead of snapping.

Six decisions below, each with the reasoning, the mockup it produced, and now the shipped Swift behind it. Nothing here touches ranking, filtering, or key handling — this is presentation only, so the existing coordinator tests stayed the proof.

⌘ Play with the real thing — an interactive HTML/JS prototype ↗ — type a query, arrow through results, try “12 * 4 + 6” or a question.

01 · Foundations

One type scale, one tint recipe

Today a 24pt input, 11.5pt chips, and seven white-opacity recipes accumulated independently. Centralizing them means every future row or control reaches for a name, not a number.

  • Badge quieted from 9/600 on 12% fill to 8.5/700 on 7% fill — it should never out-compete the title.
  • Icon-tile tint = kind color at 14% fill; tile radius derives from row radius minus icon inset (12 − 3 = 9pt).
  • Top Hit eligibility is a pure helper: first result, no active filter, non-empty. Shown as a truth table so it's directly testable.
02 · Search field

Spotlight's proportions, not a system default

Today's field is a plain 13pt TextField. Spotlight's input runs large and light — 24pt at a 300 weight — with a placeholder that's quiet rather than labeled, and an icon optically matched to the text it sits beside.

  • Input 24/300, tertiary placeholder at 35% opacity, vanishes the instant typing starts.
  • Caret & selection pick up the system accent color rather than a fixed tint.
  • Clear button shrinks and quiets to 38% opacity until hovered — present, not shouting.
03 · Result showcase

One confident Top Hit, then a quiet list

Every row reads identically today — the best match gets no more presence than the seventh. Spotlight's Top Hit lets you commit to Return without scanning. Metadata adopts Finder's own relative-date and byte-count formatting.

  • Top Hit — 46pt tile, 19/650 title, sits in its own wash (primary 4.5%), separated by a hairline and a “More results” eyebrow.
  • No filter active required — the moment a chip is selected, the user has already narrowed intent, so Top Hit disappears.
  • Metadata — “396 KB · Yesterday”, “12 items · 2 days ago” — Finder's own vocabulary, not a raw byte count and ISO date.
04 · Symbol rows

Calculator, settings, web, and assistant — finished, not bolted on

Symbol rows sit on flat colored rectangles today. The system puts them on tinted continuous-curve tiles. #27's assistant rows inherit this same language, plus the loading / answer / error states this spec defines for them.

  • Web row states its destination plainly — “Search Google for …” — with a glyph that signals leaving the app.
  • Assistant states — a pulsing dot while thinking, a body-type answer block, a quiet red error line.
  • Key chip — the selected row's Return hint reuses #1's idle-capsule hotkey chip component, not a lookalike.
05 · Empty state

A quiet message, never a void

The web fallback guarantees the unfiltered list is never empty — but filtering into “Web” with zero hits currently shows nothing at all, which reads as a rendering bug rather than a real answer.

  • Centered, tertiary-tone line naming both the active filter and the query.
  • Selection and key handling treat it as an ordinary zero-row list — no special-casing beyond the message.
06 · Motion

The panel grows — it doesn't snap

Today the panel jumps between collapsed and expanded with zero transition. A system-standard spring reads as fluid; Reduce Motion collapses the same transition to a plain crossfade. Selection itself stays instant either way, so rapid arrowing never feels laggy.

  • Panel height animates on a spring (response .42, damping .86); rows fade in fast, no slide.
  • Reduce Motion resolves to a 120ms crossfade of height and content together.
  • This preview genuinely respects prefers-reduced-motion — try it in your OS settings.

Out of scope, on purpose

  • Glass materials, filter-chip capsules, and the selection lozenge — #1's territory, this spec only reuses its key chip and radius math.
  • Keyword-engine parsing, ranking, and the process seam — #27's territory, shipped separately.
  • Grouped/sectioned results — considered, rejected, and caught once more: an early pass added a "More results" divider between Top Hit and the rest. A multi-agent Standards + Spec review flagged it as exactly the pattern this spec rejects, so it never shipped — one flat ranked list throughout, in the code and now in this deck.
