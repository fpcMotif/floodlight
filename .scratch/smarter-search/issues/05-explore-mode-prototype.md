# Explore-mode interaction prototype

Type: prototype
Status: open
Blocked by: 04

## Question

What should the explore/answer mode *feel* like inside the Floodlight panel? Build a cheap throwaway prototype (mattpocock-skills prototype skill — SwiftUI mock or even an HTML mock of the panel) showing:

- How a natural-language question ("which folder has my invoices?") is entered — same field, a mode toggle, or a prefix?
- What an answer looks like alongside/instead of the result list (answer card with cited file rows? streaming text?)
- How the user gets *out* of explore mode back to plain search.

React to it with the user; link the prototype as an asset and record the chosen interaction shape as the answer. This raises fidelity for the final spec's UI section.
