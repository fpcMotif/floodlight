# Feature brainstorm shortlist

Type: grilling
Status: open

## Question

The user asked to "brainstorm and add more good features". Run a breadth-first /grilling brainstorm and land a *prioritized shortlist* (roughly top 3–5) of new Floodlight features for the spec. Seed candidates:

- Clipboard history / snippets (the classic Raycast/Alfred draw)
- Custom quicklinks & workflows (open URL templates, run scripts)
- The documented integration boundary: Contacts, Mail, Messages, Photos, Spotlight metadata (`docs/src/content/docs/guides/search.mdx` — "Floodlight does not currently search Mail, Messages, Photos, or Contacts")
- Unit/currency conversion on top of the existing Calculator
- Emoji & symbol search
- Window management commands
- Browser tabs/bookmarks/history search
- Menu-bar command search (search the frontmost app's menus)
- A plugin/extension system vs. building sources in-core

For each shortlisted feature: one-line scope and why it made the cut; for the rejects: one line on why not (feeds Out of scope or fog). The shortlist graduates into per-feature fog entries on the map.
