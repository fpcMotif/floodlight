## Requirements

- macOS 14 or later on Apple silicon
- Xcode Command Line Tools (`codesign`, `sips`, `iconutil`, and the macOS SDK)
- Zig 0.17.0 (fetched into `.tools/` by `make install-zig`)
- [Bun](https://bun.sh) only when working on this documentation site

<Steps>

1. **Clone the repository**

   ```sh
   git clone https://github.com/fpcMotif/nanospot.git
   cd nanospot
   ```

2. **Install the pinned toolchain and run checks**

   ```sh
   make install-zig
   make check
   ```

3. **Create the application bundle**

   ```sh
   make bundle
   open app/zig-out/Nanospot.app
   ```

</Steps>

<Aside type="caution" title="Local builds are ad-hoc signed">
  `make bundle` signs `app/zig-out/Nanospot.app` ad-hoc with bundle identifier
  `com.nanospot.app` unless `-Dsign-identity` names a Developer ID Application
  certificate. Ad-hoc builds are for development and are not equivalent to a
  notarized release asset.
</Aside>

## Icon assets

`app/icon/Nanospot.png` is the 1024-pixel application icon master used by Finder
and the app bundle. `scripts/build-app-icon.sh` generates `Nanospot.icns` from
it automatically during `make bundle`.

## Documentation

```sh frame="none"
cd docs
bun install
bun run dev
```

Run `bun run build` (or `make docs` from the repository root) before submitting
documentation changes. Astro emits the static site under `docs/dist`. When
changing the interactive hero stage under `docs/demo`, run
`bun --cwd=docs/demo run build` first to update `docs/public/demo/`.
