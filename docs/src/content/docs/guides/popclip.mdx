---
title: PopClip
description: Trigger the same web search destinations from selected text with PopClip.
---

Nanospot keeps web search destinations (Google, YouTube, X, and Grok) out of
any custom URL scheme. Because they use standard search URLs, a lightweight
[PopClip](https://pilotmoon.com/popclip/) extension can open the same sites from
selected text anywhere on your Mac without launching Nanospot.

## Why no Nanospot-PopClip integration exists

Adding a custom `nanospot://` deep-link handler adds URL parsing and app
activation code for no gain when PopClip can open the destination URL directly.
Mirroring the URL list keeps zero PopClip-specific code inside Nanospot.

## Setting up the matching PopClip extension

Create a folder named `Nanospot Web.popclipext` containing a `Config.plist`
with one URL action per web engine. PopClip substitutes `***` with the selected
text. Check the [PopClip developer docs](https://www.popclip.app/dev/) if your
PopClip version uses an updated schema.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Actions</key>
    <array>
        <dict>
            <key>Title</key>
            <string>Search Google</string>
            <key>Url</key>
            <string>https://www.google.com/search?q=***</string>
        </dict>
        <dict>
            <key>Title</key>
            <string>Search YouTube</string>
            <key>Url</key>
            <string>https://www.youtube.com/results?search_query=***</string>
        </dict>
        <dict>
            <key>Title</key>
            <string>Search X</string>
            <key>Url</key>
            <string>https://x.com/search?f=live&amp;q=***</string>
        </dict>
        <dict>
            <key>Title</key>
            <string>Search Grok</string>
            <key>Url</key>
            <string>https://grok.com/?q=***</string>
        </dict>
    </array>
</dict>
</plist>
```

Double-click `Nanospot Web.popclipext` to install it into PopClip.
