---
title: Keyboard shortcuts
description: Control Search and Clipboard History without leaving the keyboard.
---

## Global hotkeys

<ul class="fl-shortcuts">
  <li><span>Open or close Search</span><kbd>⌥ Space</kbd></li>
  <li><span>Open or close Clipboard History</span><kbd>⌥ ⇧ C</kbd></li>
</ul>

## Search panel

<ul class="fl-shortcuts">
  <li><span>Previous or next result</span><kbd>↑ / ↓</kbd></li>
  <li><span>Open selected result</span><kbd>Return</kbd></li>
  <li><span>Dismiss panel</span><kbd>Escape</kbd></li>
  <li><span>Accept inline completion</span><kbd>→ / Tab</kbd></li>
  <li><span>Accept next word of completion</span><kbd>⌥ →</kbd></li>
  <li><span>Copy selected result path or URL</span><kbd>⌘ C</kbd></li>
  <li><span>Copy selected result, alternate</span><kbd>⌥ Return</kbd></li>
  <li><span>Reveal selected app or file in Finder</span><kbd>⌘ R</kbd></li>
  <li><span>Reveal in Finder, alternate</span><kbd>⌘ Return</kbd></li>
  <li><span>Open 2nd to 6th frequent app when empty</span><kbd>⌘ 2 … ⌘ 6</kbd></li>
  <li><span>Clear local query history</span><kbd>⇧ ⌘ ⌫</kbd></li>
  <li><span>Clear app open counts</span><kbd>⌥ ⌘ ⌫</kbd></li>
</ul>

## Filter chips

<ul class="fl-shortcuts">
  <li><span>All results (or All copies on board)</span><kbd>⌘ 1</kbd></li>
  <li><span>Applications (or Text on board)</span><kbd>⌘ 2</kbd></li>
  <li><span>Files</span><kbd>⌘ 3</kbd></li>
  <li><span>Folders (or Images on board)</span><kbd>⌘ 4</kbd></li>
  <li><span>First visible dynamic search filter</span><kbd>⌘ 5</kbd></li>
</ul>

## Clipboard History board

<ul class="fl-shortcuts">
  <li><span>Paste into previous app (or copy)</span><kbd>Return</kbd></li>
  <li><span>Copy entry without pasting</span><kbd>⌘ C / ⌥ Return</kbd></li>
  <li><span>Open link in browser</span><kbd>⌘ O</kbd></li>
  <li><span>Reveal copied file in Finder</span><kbd>⌘ R / ⌘ Return</kbd></li>
  <li><span>Toggle Quick Look preview</span><kbd>Space / ⌘ Y</kbd></li>
  <li><span>Open actions menu</span><kbd>⌘ K</kbd></li>
  <li><span>Pin or unpin entry</span><kbd>⌘ .</kbd></li>
  <li><span>Delete entry</span><kbd>⌘ D</kbd></li>
  <li><span>Return to Search when filter is empty</span><kbd>⌫</kbd></li>
</ul>

<kbd>Space</kbd> triggers Quick Look only when the board filter field is empty.
