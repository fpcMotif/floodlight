---
title: Search
description: Find applications, files, folders, direct links, and web results from one panel.
---

Nanospot focuses the search field when the panel opens on <kbd>⌥ Space</kbd>.
Start typing at once. Press <kbd>Return</kbd> to open the selected row.

When the search field is empty, Nanospot lists your most-opened apps. Press
<kbd>⌘ 2</kbd> through <kbd>⌘ 6</kbd> to launch rows 2 to 6 directly, or press
<kbd>Return</kbd> for the top row.

## Applications

Nanospot indexes apps in `/Applications`, `/Applications/Utilities`,
`/System/Applications`, `/System/Applications/Utilities`, and `~/Applications`
on launch. Each `.app` bundle appears as one launchable result, and apps outrank
file rows with the same score.

## Files and folders

Search covers filenames and folder paths under your home directory (`$HOME`)
using the memory-mapped File Index (`names.flix`).

- Press <kbd>Return</kbd> to open the selected item.
- Press <kbd>⌘ R</kbd> or <kbd>⌘ Return</kbd> to reveal it in Finder.
- Press <kbd>⌘ C</kbd> or <kbd>⌥ Return</kbd> to copy its path or URL.

## Paths

Type a `/` to match against full relative paths under `$HOME` instead of
matching only the filename. Without `/`, Nanospot matches the filename first and
checks ancestor folders only if needed.

## Inline query completion

When the caret sits at the end, Nanospot suggests gray completions from local
query history, the Top Hit title, and Google suggestions.

- Press <kbd>→</kbd> or <kbd>Tab</kbd> to accept the full completion.
- Press <kbd>⌥ →</kbd> to accept the next word.
- Press <kbd>⇧ ⌘ ⌫</kbd> to clear local query history.
- Press <kbd>⌥ ⌘ ⌫</kbd> to clear app open counts.

## Direct links

A query shaped like a web address produces a link row above web searches:

```text
https://example.com/docs   opens as typed
example.com/docs           opens https://example.com/docs
localhost:3000             opens http://localhost:3000
127.0.0.1:8080/a           opens http://127.0.0.1:8080/a
```

Press <kbd>Return</kbd> to open it in your default browser, or <kbd>⌘ C</kbd>
to copy the URL. Queries with whitespace or non-`http`/`https` schemes stay
ordinary searches.

## Web results and suggestions

Every non-empty text query includes a **Google** row followed by **YouTube**,
**X**, and **Grok** search rows. Nanospot shows up to four cached or fetched
Google suggestions for text queries of two or more characters. Paths and links
receive no suggestions.

## Clipboard History

Press <kbd>⌥ ⇧ C</kbd> from any app to open Clipboard History. History rows
appear on the left, and the Clipboard Inspector appears on the right.

- Filter with <kbd>⌘ 1</kbd>–<kbd>⌘ 4</kbd> for **All**, **Text**, **Files**,
  and **Images**.
- Inspect full copied text with code line numbers, color swatches, images, or
  file previews.
- Press <kbd>Return</kbd> to copy and send <kbd>⌘ V</kbd> to the previous app
  (requires Accessibility permission), or <kbd>⌘ C</kbd> / <kbd>⌥ Return</kbd>
  to copy only.
- Press <kbd>⌘ O</kbd> to open a copied URL.
- Press <kbd>⌘ R</kbd> to reveal a copied file in Finder.
- Press <kbd>Space</kbd> or <kbd>⌘ Y</kbd> for Quick Look.
- Press <kbd>⌘ K</kbd> for actions, <kbd>⌘ .</kbd> to pin, and <kbd>⌘ D</kbd> to
  delete.
- Press <kbd>⌫</kbd> when the board filter field is empty to switch back to Search.

## Not currently searchable

Nanospot matches filenames, app names, URLs, and web engines. It does not index
file contents, System Settings panes, Mail, Messages, Photos, or Contacts.
