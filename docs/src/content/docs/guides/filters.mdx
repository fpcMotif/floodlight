---
title: Filters
description: Narrow search results and Clipboard History by kind with chips or keyboard shortcuts.
---

The filter bar sits directly between the search field and the result list. Filter
chips let you switch result families with one shortcut without losing your
query.

## Search filters

### Always visible

| Filter | Contents | Shortcut |
| --- | --- | --- |
| **All** | Every matching result | <kbd>⌘ 1</kbd> |
| **Apps** | Application bundles | <kbd>⌘ 2</kbd> |
| **Files** | Regular files | <kbd>⌘ 3</kbd> |
| **Folders** | Directories | <kbd>⌘ 4</kbd> |

While the background File Index scan is running, non-app filter chips display a
loading spinner instead of a count.

### Dynamic filters

When the current result list contains matching items, Nanospot appends these
chips after **Folders**:

- **PDFs**
- **Images**
- **Documents**

<kbd>⌘ 5</kbd> selects the first visible dynamic filter. Click any chip directly
to select it, or scroll horizontally when many chips appear.

## Clipboard History filters

Clipboard History (<kbd>⌥ ⇧ C</kbd>) shows four chips: **All**, **Text**,
**Files**, and **Images**, bound to <kbd>⌘ 1</kbd>–<kbd>⌘ 4</kbd>. Typing filters
only within the selected chip.

## Pointer and keyboard behavior

- Hovering a row highlights it without moving the keyboard selection.
- Single-clicking a row selects it; double-clicking runs its primary action.
- Clicking a filter chip keeps keyboard focus in the search field.
- Pressing <kbd>Escape</kbd> or switching surfaces keeps your session for five
  minutes by default.
