The filter row sits directly above results so slower file matches cannot arrive
silently below the fold.

## Always-visible filters

| Filter | Contents | Shortcut |
| --- | --- | --- |
| **All** | Every matching result | <kbd>⌘ 1</kbd> |
| **Apps** | Application bundles | <kbd>⌘ 2</kbd> |
| **Files** | Regular files | <kbd>⌘ 3</kbd> |
| **Folders** | Directories | <kbd>⌘ 4</kbd> |

Each chip shows either a compact count or a spinner while that source is still
loading.

## Dynamic filters

A filter appears only when the current results make it useful:

- **Settings**
- **PDFs**
- **Images**
- **Documents**

This keeps the control row short for simple app searches while making richer
file searches easier to inspect. Dynamic filters appear after the four stable
filters in the order above. <kbd>⌘ 5</kbd> selects the first visible dynamic
filter; any others remain available by clicking their chips.

## Pointer and keyboard behavior

- Hovering a result gives immediate visual feedback without changing the
  keyboard selection.
- Single-clicking selects a result; double-clicking opens it.
- Clicking a filter keeps the insertion point in the search field.
- Arrow-key selection never animates the result stack or changes panel position.
