Floodlight tries <kbd>⌘ Space</kbd> first. If another macOS feature already owns
that global shortcut, Floodlight registers <kbd>⌥ Space</kbd> instead.

## Disable Spotlight’s shortcut

1. Select **Replace Spotlight…** in the setup window. After setup, the same
   action is available from the menu-bar flashlight under **Settings…**.
2. In the macOS shortcut controls, select **Spotlight**.
3. Turn off **Show Spotlight search**.
4. Return to Floodlight. It retries <kbd>⌘ Space</kbd> automatically.

If the shortcut does not switch, select <kbd>⌘ Space</kbd> once. No restart is
required.

## Check Input Sources

If <kbd>⌘ Space</kbd> still does not work:

1. Open **System Settings → Keyboard → Keyboard Shortcuts → Input Sources**.
2. Disable or change any language-switching action using <kbd>⌘ Space</kbd>.
3. Return to **Settings…** and select <kbd>⌘ Space</kbd> again.

## Confirm it is working

Press <kbd>⌘ Space</kbd> once from another application. Floodlight should appear
above the current app with the insertion point already in the search field.
Press it again, press <kbd>Escape</kbd>, or click outside the panel to dismiss.

## Re-enable Spotlight later

Disabling the shortcut does not remove Spotlight. To restore it:

1. Click the Floodlight menu-bar flashlight and choose **Settings…**.
2. Select <kbd>⌥ Space</kbd> so <kbd>⌘ Space</kbd> is free.
3. Open **System Settings → Keyboard → Keyboard Shortcuts → Spotlight**.
4. Turn on **Show Spotlight search**, then select **Done**.

Afterward, <kbd>⌘ Space</kbd> will open Spotlight and <kbd>⌥ Space</kbd> will
open Floodlight.

## What this changes

Floodlight does not depend on Spotlight for filenames, folders, applications, or
settings; it maintains its own local index. Disabling the **keyboard shortcut**
does not disable macOS metadata indexing. Leave Spotlight indexing enabled if
other apps use it for content search.
