---
title: Shortcuts & Spotlight
description: How Nanospot shortcuts avoid conflicting with Spotlight on Command-Space.
---

Nanospot uses <kbd>⌥ Space</kbd> for search and <kbd>⌥ ⇧ C</kbd> for Clipboard
History, so macOS Spotlight keeps <kbd>⌘ Space</kbd> without a conflict.

## Default global shortcuts

- **Search panel**: <kbd>⌥ Space</kbd>
- **Clipboard History**: <kbd>⌥ ⇧ C</kbd>

Both hotkeys register through Carbon on launch, so pressing the active hotkey
summons that surface or hides it if it is already focused.

## Turning off Spotlight (optional)

If you want to stop Spotlight from opening on <kbd>⌘ Space</kbd> so another tool
can use that key combination:

1. Open **System Settings → Keyboard → Keyboard Shortcuts → Spotlight**.
2. Turn off **Show Spotlight search**.
3. Open **System Settings → Keyboard → Keyboard Shortcuts → Input Sources** if
   language switching also binds <kbd>⌘ Space</kbd>.

## Confirming Nanospot shortcuts work

Press <kbd>⌥ Space</kbd> from another app. Nanospot opens centered on the screen
holding the pointer with focus in the search field. Press <kbd>⌥ Space</kbd>,
<kbd>Escape</kbd>, or click outside the panel to dismiss it.

## What Nanospot leaves unchanged

Nanospot builds and queries its own local File Index under `$HOME` (`names.flix`).
It does not touch macOS Spotlight indexing (`mds` / `mdworker`). Leave Spotlight
indexing enabled if Finder or other apps rely on it.
