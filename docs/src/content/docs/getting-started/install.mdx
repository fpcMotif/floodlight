## System requirements

- Apple-silicon Mac
- macOS 14 Sonoma or later
- 10 MB of free disk space

## Install

<Steps>

1. Open `Nanospot.dmg`.
2. Drag **Nanospot** to **Applications**.
3. Eject the Nanospot disk image.
4. Open `/Applications/Nanospot.app`.

</Steps>

## Permissions

### Full Disk Access

Nanospot indexes your home directory (`$HOME`). Without Full Disk Access, macOS
blocks access to Desktop, Documents, Downloads, and other protected folders.

On first launch without Full Disk Access, Nanospot opens **System Settings →
Privacy & Security → Full Disk Access** beside a floating card:

1. Drag the Nanospot icon from the floating card into the Full Disk Access list
   (or click **+** and select `/Applications/Nanospot.app`).
2. Authenticate when macOS prompts you.
3. Nanospot detects the grant automatically and rebuilds the File Index in the
   background.

If you dismiss the card before granting access, enable Nanospot manually in
**System Settings** and relaunch Nanospot to trigger a fresh scan.

### Accessibility (for direct paste)

When you press <kbd>Return</kbd> on Clipboard History, Nanospot copies the
entry and sends <kbd>⌘ V</kbd> to the previously active application. macOS
prompts for **Accessibility** permission the first time you paste into another
app. Without Accessibility permission, <kbd>Return</kbd> still copies the entry
so you can paste it manually.

## Launch at login

Add **Nanospot** under **System Settings → General → Login Items & Extensions**
if you want it to start automatically when you sign in.

## Update

Download the newest DMG, quit Nanospot, and replace the existing copy in
`/Applications`.
