## Findings considered and rejected

- SQLite writes on Return: WAL with `synchronous=NORMAL` does not sync to disk on commit.
- Per-row `stat` and date formatting: 202 µs at p99 for a whole built frame.
- Clipboard board query on switch: 0.73 ms for 5,000 entries.
- Persistent search thread pool: a whole query including its spawns costs 0.49 ms.
- Two-process split (agent plus on-demand UI): cold UI launch breaks the summon budget.
